# Etat du projet au transfert — sans survente

## Disponible / vérifié antérieurement

- Règles intégrales V3.0 dans le kit, incluant variantes, Signatures, Insight/Techniques et cas limites.
- Simulateur V3.2 JS indépendant du futur RPG avec tests existants et journal explicatif T2.
- Delta d'affinité de Rang implémenté dans le simulateur V3.1/V3.2, non encore réédité dans le contrat V3.0 historique.
- Audité en lecture : dépôt GitHub `juniorbattle/RPG-ArtByCode`, `AGENTS.md`, extraits du `JOURNAL.md`, `package.json`, structure source et outils, commit recent `d7c439b3b08280d7643d8cfe3f658de6ad49b928` au moment de l'audit. Il ne constitue pas un sous-module obligatoire.
- Le simulateur est une référence de logique/régression : son UX antérieure est jugée compliquée et son art actuel n'est PAS la cible.

## Non disponible à ce jour dans le projet de production

- Aucun repo spécifique nouveau configuré par ce kit, aucune branche/PR/commit de production, ni aucune génération HD-2D finale.
- Pas de preuve que les scripts de production tournent : ils doivent être créés et exécutés par Claude Code.
- Pas de test ergonomique de bout en bout de la future UI direct-manipulation.
- Pas de cahier de mise en scène final : caméras, décors, environnement urbain, personnages et UX RPG hors combat sont encore ouverts.
- Les estimations de performance du dépôt de référence sont liées à son hardware/scène ; ne jamais les recopier comme baseline de ce projet.

## Ce que Claude doit rapporter

Un inventaire **vrai** du code produit et exécuté à chaque pass, toute divergence entre moteur prototype et nouveau moteur, un échantillon de captures/vidéos, la liste de dettes et une proposition de prochain chantier soumise au responsable.
